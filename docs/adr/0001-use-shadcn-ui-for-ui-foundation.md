# Use shadcn/ui for the UI foundation

Status: accepted

Senja Painters V1 will use shadcn/ui with Radix-backed primitives as the standard UI foundation for public forms, navigation controls, dialogs, filters, tables, and admin screens. This gives the project accessible interaction patterns and repo-owned component code that can be customized as the brand matures, at the cost of maintaining copied component files and their supporting dependencies over time.
